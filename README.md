# Ficbook Enhancer

Расширение для Chromium, которое настраивает интерфейс [Ficbook](https://ficbook.net/) и позволяет сохранить текущую работу в FB2. Это независимый проект и не является продуктом Ficbook.

## Возможности

- Настройка фона, цветов, шрифтов и положения кнопки панели.
- Скрытие Premium, промо внутри глав и жанров из ленты.
- Удаление пустых блоков «Промо», «Горячие работы» и «Горячие заявки» после фильтрации.
- Экспорт работы и всех её глав в FB2 с текстовой аннотацией из карточки работы.
- Защита долгого экспорта: переход по обычной ссылке открывается в новой вкладке, а закрытие или перезагрузка страницы вызывает предупреждение браузера.

## Установка

После публикации ссылка на Chrome Web Store появится здесь.

Для локальной проверки:

1. Установите Node.js с npm.
2. Выполните `npm ci` в корне проекта.
3. Выполните `npm run build`.
4. Откройте `chrome://extensions`, включите режим разработчика и выберите «Загрузить распакованное расширение».
5. Укажите папку `dist`.

## Данные и приватность

Расширение не создаёт аккаунт, не содержит аналитику и не отправляет настройки, содержимое Ficbook или выбранные пользователем файлы разработчику.

Настройки интерфейса, выбранные фоновые изображения и шрифты хранятся локально в браузере: в `chrome.storage.local`, IndexedDB и `localStorage`. При экспорте FB2 текст текущей работы и её глав обрабатывается в браузере и сохраняется только в скачиваемый файл.

Если пользователь указывает URL фоновой картинки, браузер загружает её с указанного пользователем сайта. Подробнее: [политика конфиденциальности](PRIVACY.md).

## Разрешения

| Разрешение | Зачем нужно |
| --- | --- |
| `storage` | Сохранять локальные настройки расширения. |
| `*://ficbook.net/*` | Показывать панель на Ficbook, настраивать интерфейс и собирать главы для FB2. |

## Разработка и проверка

```powershell
npm run lint
node --test tests/ficbook-enhancer.test.js tests/genre-styles.test.js tests/panel-ui.test.js tests/fb2-export.test.js tests/theme-preview.test.js tests/release-readiness.test.js
npm run build
```

После сборки папка `dist` содержит распакованное расширение. Подписывающие ключи и готовые архивы намеренно не входят в Git.

## Ограничения

- Расширение рассчитано на Chromium и Ficbook; изменения разметки Ficbook могут потребовать обновления селекторов.
- У расширения нет сервера и синхронизации настроек между устройствами.
- Текст системного предупреждения при закрытии страницы задаёт сам браузер.
