## Что умеет

- Настраивать фон, цвета, шрифты и положение кнопки панели.
- Скрывать Premium, промо внутри глав и выбранные жанры из ленты.
- Убирать пустые блоки «Промо», «Горячие работы» и «Горячие заявки», если фильтры скрыли всё содержимое.
- Сохранять работу и все её главы в FB2 с текстовой аннотацией из карточки работы.
- Не прерывать долгий экспорт при переходе по обычной ссылке: новая страница откроется в другой вкладке.
- Предупреждать браузером о закрытии или перезагрузке страницы во время экспорта.

Расширение работает только на Ficbook и является независимым проектом: оно не связано с Ficbook и не является его официальным продуктом.

## Установка

### Быстрый способ — готовая сборка

1. Скачайте [Ficbook Enhancer 1.0.0](https://github.com/pradigmaz/ficbook-enhancer/releases/latest/download/ficbook-enhancer-1.0.0.zip).
2. Полностью распакуйте ZIP в отдельную папку.
3. Откройте страницу расширений своего браузера из таблицы ниже.
4. Включите **Режим разработчика**.
5. Нажмите **«Загрузить распакованное расширение»** / **Load unpacked** и выберите папку из шага 2.
   В выбранной папке должен лежать файл `manifest.json`, а не ZIP-архив и не папка уровнем выше.
6. Откройте или обновите страницу Ficbook. Кнопка **FB Enhancer** появится снизу слева.

### Где открыть «Расширения»

| Браузер | Введите в адресную строку | Через меню, если удобнее |
| --- | --- | --- |
| Google Chrome | `chrome://extensions` | `⋮` → «Расширения» → «Управление расширениями» |
| Microsoft Edge | `edge://extensions` | `…` → «Расширения» → «Управление расширениями» |
| Brave | `brave://extensions` | `☰` → «Расширения» → «Управление расширениями» |
| Opera | `opera://extensions` | Меню Opera → «Расширения» → «Расширения» |
| Vivaldi | `vivaldi://extensions` | Меню Vivaldi → «Инструменты» → «Расширения» |
| Яндекс Браузер | `browser://extensions` | Меню → «Дополнения» |
| Другой Chromium-браузер | `chrome://extensions` | Ищите пункт «Расширения» или «Дополнения» в главном меню |

После установки можно закрепить значок в панели браузера и открывать настройки оттуда. При обновлении готовой сборки распакуйте новый ZIP и нажмите кнопку перезагрузки `↻` на странице расширений.

### Сборка из исходников

Нужен установленный Node.js с npm:

```powershell
npm ci
npm run build
```

Затем загрузите распакованную папку `dist` тем же способом. Не добавляйте в браузер `dist.pem`, `.crx` или исходный ZIP.

## Данные и приватность

Расширение не создаёт аккаунт, не содержит рекламу или аналитику и не отправляет разработчику настройки, текст работ или выбранные файлы.

Настройки интерфейса, фоновые изображения и шрифты хранятся локально в браузере: в `chrome.storage.local`, IndexedDB и `localStorage`. При экспорте FB2 текст работы и её глав обрабатывается прямо в браузере и сохраняется только в скачиваемый файл.

Если указать URL фоновой картинки, браузер загружает её непосредственно с выбранного сайта. Полные условия: [политика конфиденциальности](PRIVACY.md).

## Разрешения

| Разрешение | Зачем нужно |
| --- | --- |
| `storage` | Сохранять локальные настройки расширения. |
| `*://ficbook.net/*` | Показывать панель на Ficbook, настраивать страницу и собирать главы для FB2. |

## Обновление и помощь

- Новые сборки будут появляться в [Releases](https://github.com/pradigmaz/ficbook-enhancer/releases).
- Если Ficbook изменит разметку, отдельные элементы могут перестать скрываться или извлекаться для FB2. Сообщите о проблеме через [Issues](https://github.com/pradigmaz/ficbook-enhancer/issues) и приложите ссылку на страницу, описание и скриншот без личных данных.
- Firefox не поддерживается: расширение подготовлено для браузеров на Chromium.
